# 🦸 MCU Archive

### Marvel Cinematic Universe Timeline & Character Encyclopedia

A complete **Marvel Cinematic Universe archive** for exploring MCU movies, series, special presentations, characters, timelines, and personal watch progress.

The project is designed as a single interactive experience for discovering the MCU from **Phase One through the Multiverse Saga**.

---

## 🎬 Features

### MCU Timeline

* Complete MCU chronology
* Movies, Disney+ series, and special presentations
* Browse titles by phase
* Sort titles by release date
* Expand individual titles for more information
* Search titles by name
* Phase-based watch progress
* Watched and unwatched status tracking

### 📊 Watch Progress Dashboard

The dashboard provides a personal overview of your MCU journey.

* Total titles
* Watched titles
* Remaining titles
* Completion percentage
* Visual progress bar
* Continue Watching
* Jump directly to the next title
* Completion celebration when everything is watched

### 🦸 Character Encyclopedia

Explore MCU characters including:

* Heroes
* Villains
* Anti-Heroes
* Cosmic beings
* Gods
* Mutants
* Aliens
* Humans
* Synthetic characters

Character profiles include information such as:

* Name
* Alias
* Species
* Affiliation
* Status
* First appearance
* Powers
* Abilities
* MCU appearances

### 🔎 Character Search & Filtering

Characters can be explored using:

* Character search
* Affiliation filtering
* Phase filtering
* Character categories
* Favorites
* Reset filters
* Popular character shortcuts

### ⭐ Favorites

Save characters as favorites and quickly access your preferred MCU characters.

### 🎭 Character Profiles

Each character has an interactive profile containing detailed information and their MCU appearances.

You can also:

* Open their first appearance
* Jump directly to the related timeline title
* View their appearances
* Mark all appearances as watched
* Unmark all appearances
* Add or remove the character from favorites
